# Perfect Properties — UX case study

Case study and clickable screen walkthrough by Suvarna Myneni.

- Case study: `index.html`
- Interactive walkthrough: `walkthrough.html` (hotspots link screens; arrow keys for next/prev; H shows hotspots; long screens scroll)
- Screen data: `screens.json` (source) and `screens.js` (loaded by the walkthrough)

Screens and kit images come from the Perfect Properties UI Kit Figma file: Final screens, Design, components, Typography, Icons, and IOS Components. Listing content is sample data.

The Design page is a flow map of five rows — Sign Up, Onboarding, Property Navigation, Compare Properties, and Mortgage application. The full page is `img/design-flow-map.webp`. Each row is a separate image in `img/flow-*.webp`. Search Charlotte and Property w animation are cropped from the Property Navigation row (`img/search-charlotte.webp`, `img/property-w-animation.webp`) because they are not part of the 32-screen walkthrough.

UI kit images from the components page are `img/kit-*.webp`. The iOS board is `img/ios-components.webp`. Loose components from the Design page are `img/loose-components.webp`.

The file has no research. The case study says so. Maya Reddy, in Personas & research, is labeled as a proto-persona and is illustrative only.
